## Use When

Use when deciding between primary and secondary actions.

## Do

- Keep one clear primary action per section.
- Use secondary actions for navigation or cancellation.
- Match link versus button semantics to the interaction.

## Do Not

- Promote every action to primary.
- Assume button variants are identical across package majors.

## Example

Settings pages usually end with one save action and one secondary cancel action.
