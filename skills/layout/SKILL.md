## Use When

Use when organizing page sections and component rhythm.

## Do

- Start with Stack for vertical spacing.
- Keep page shells in apps and primitives in packages.
- Use consistent spacing between header, feedback, and content.

## Do Not

- Encode app-specific page shells inside shared components.
- Mix unrelated layout styles in one page.

## Example

Use a page shell class in the app and Stack for section ordering.
