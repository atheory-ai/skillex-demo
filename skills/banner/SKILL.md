## Use When

Use a Banner for high-priority messages that need to remain visible near the relevant task or page section.

## Do

- Keep the title short and specific.
- Choose the tone from the user impact, not the implementation detail.
- Include an action only when there is a clear next step.

## Do Not

- Assume the Banner API from memory; this repo contains multiple major versions.
- Use a banner for inline field validation.

## Example

Use a success banner for a confirmed campaign state and a warning banner for time-sensitive merchandising.
