## Use When

Use when creating or revising top-level page introductions.

## Do

- Use one primary title per page.
- Add eyebrow text only when it clarifies the page domain.
- Keep descriptions short and task-oriented.

## Do Not

- Use banner copy as the page title.
- Repeat the same information in eyebrow and title.

## Example

An admin page can use an operational eyebrow; storefront can use a campaign eyebrow.
