# Next.js App Router Conventions

This app represents a newer App Router codebase.

## Routing

- Route files live under `app/`.
- Prefer server component page files unless interactivity is required.
- Shared route composition should use layouts and colocated segments.

## Demo reminder

When the task mentions a CTA or button in this app, the relevant package API is the v2 `@demo/component-library` install.
