## Use When

Use when adding UI that includes navigation, forms, or feedback.

## Do

- Keep labels explicit.
- Use links for navigation and buttons for actions.
- Make feedback meaningful without relying on color alone.

## Do Not

- Assume component defaults cover page-level accessibility.
- Hide critical guidance only in visuals.

## Example

Link ErrorSummary items to the relevant controls and keep Banner copy understandable without icons.
