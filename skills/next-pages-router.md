# Next.js Pages Router Conventions

This app represents an older Next.js codebase.

## Routing

- Route files live under `pages/`.
- Page components should be default exports from files in `pages/`.
- Favor simple page-level composition instead of App Router layouts.

## Demo reminder

When the task mentions a CTA or button in this app, the relevant package API is the v1 `@demo/component-library` install.
