## Use When

Use when multiple controls form one conceptual group.

## Do

- Give each group a clear legend.
- Add a short description when the group has workflow impact.
- Keep related actions outside the fieldset unless they directly affect that group.

## Do Not

- Use fieldsets as generic layout wrappers.
- Nest unrelated groups together to save space.

## Example

Promotion thresholds and escalation contacts belong in separate groups.
