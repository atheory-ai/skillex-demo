## Use When

Use when the same component appears in admin and storefront with different intent.

## Do

- Keep admin copy operational and directive.
- Keep storefront copy customer-facing and benefit-led.
- Use neutral phrasing when guidance spans both surfaces.

## Do Not

- Assume reusable components imply reusable copy.
- Copy incident-management language into customer pages.

## Example

Admin: "3 approvals pending." Storefront: "15 percent off selected bundles."
