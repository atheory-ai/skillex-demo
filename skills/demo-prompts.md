# Demo Prompts

Use prompts that naturally collide across versions and scopes.

## Good examples

- Add a CTA button linking to `/signup`.
- Add a hero callout to the homepage.
- Update routing for this page.
- Explain how to work on the component library itself.

## What to compare

- Same prompt in `apps/next-legacy` versus `apps/next-modern`.
- Package summary results versus path-scoped results.
- Public package guidance versus private maintainer notes.
