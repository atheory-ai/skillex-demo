## Use When

Use when a task touches labels, navigation, validation, or page-level feedback.

## Do

- Keep interactions semantic: links navigate, buttons act.
- Preserve meaningful labels and linked validation summaries.
- Make status understandable without relying on color or iconography.

## Do Not

- Assume package defaults fully solve page-level accessibility.
- Hide blocking requirements inside decorative copy.

## Example

Banner text should still be meaningful if the icon is ignored.
