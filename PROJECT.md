# Project

This monorepo tests whether deterministic, scoped skill retrieval improves agent
work compared with a broad root-only skill corpus.

The application code deliberately contains overlapping truths: two Next.js majors,
two incompatible majors of `@demo/design-system`, app-specific communication
styles, and consumer-versus-maintainer guidance.

The `main` and `skillex-0.9` branches keep application source equivalent while
changing the guidance and retrieval system available to the agent.
