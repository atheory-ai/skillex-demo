## Use When

Use when adding feedback, forms, or actions with v3 components.

## Do

- Keep Banner text meaningful without relying on color.
- Link ErrorSummary items to invalid controls.
- Use real links for navigation and buttons for actions.

## Do Not

- Put interactive elements inside headings.
- Replace labels with placeholder text.

## Example

Critical Banner tone uses assertive live region behavior; use it only for blocking or urgent messages.
