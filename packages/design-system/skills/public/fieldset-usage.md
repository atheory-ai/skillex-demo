## Use When

Use when several inputs belong to one decision or setting group.

## Do

- Give each group a clear legend.
- Add a short description when the group affects workflow.
- Keep controls inside the fieldset closely related.

## Do Not

- Use Fieldset as a generic card substitute.
- Combine unrelated concerns in one group.

## Example

Promotion controls and escalation contacts should be separate groups.
