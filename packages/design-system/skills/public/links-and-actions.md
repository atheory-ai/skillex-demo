## Use When

Use when a UI element might be either navigation or an in-place action.

## Do

- Use links for navigation to another route.
- Use buttons for submit or local state changes.
- Keep wording aligned with the destination or effect.

## Do Not

- Blur navigation and submission semantics.
- Treat every CTA as interchangeable.

## Example

Use a link-style Button in Banner actions that move to another page.
