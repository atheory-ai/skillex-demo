## Use When

Use when choosing spacing, tone, or density in v3 component composition.

## Do

- Prefer `Stack` gaps of `sm`, `md`, or `lg`.
- Use tone values consistently: `info`, `success`, `warning`, `critical`.
- Keep app CSS for page layout, not component internals.

## Do Not

- Encode arbitrary spacing into copied component markup.
- Use tone as brand decoration.

## Example

Use `gap="lg"` between page sections and `gap="md"` inside form flows.
