## Use When

Use when rendering primary or secondary actions in app code.

## Do

- Use `href` for navigation.
- Use button semantics for in-place actions.
- Keep one clear primary action in a section.

## Do Not

- Use Button variants to signal unrelated meaning.
- Put navigation behavior on plain buttons without a reason.

## Example

Banner CTAs that navigate should use `<Button href=\"/promotions\">`.
