## Use When

Use when rendering a page title, eyebrow, and description.

## Do

- Use one PageHeader at the start of the page surface.
- Keep eyebrow optional and meaningful.
- Keep descriptions supportive, not repetitive.

## Do Not

- Use PageHeader as a substitute for section headings.
- Repeat banner copy in the page description.

## Example

Lead the promotions page with a PageHeader, then follow with a Banner.
