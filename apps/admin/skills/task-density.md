## Use When

Use when deciding how much content fits in one admin view.

## Do

- Keep high-signal information close together.
- Favor compact spacing when tasks are sequential.
- Use panels and grouped metrics sparingly and clearly.

## Do Not

- Expand admin pages into airy storefront layouts.
- Trade scanability for visual drama.

## Example

Dashboards can use small metric panels under one concise status banner.
