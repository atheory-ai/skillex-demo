## Use When

Use when adding links between admin sections.

## Do

- Keep navigation labels aligned with operational domains.
- Make destination routes predictable.
- Use link-based secondary actions for navigation.

## Do Not

- Replace task actions with navigation links.
- Introduce consumer-facing route names.

## Example

Use "View campaign" as a navigation action from a dashboard banner.
