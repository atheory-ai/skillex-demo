## Use When

Use when admin pages have multiple available actions.

## Do

- Keep the primary operational action nearest the relevant status.
- Relegate escape hatches and navigation to secondary treatment.
- Use concise labels that describe the operation.

## Do Not

- Give dashboard pages multiple competing primary actions.
- Use storefront CTA patterns in admin.

## Example

"Save settings" is primary; "Cancel" is secondary.
