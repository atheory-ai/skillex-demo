# Evaluation Tasks

The coordinating agent selects one or more tasks and gives identical wording to
both trial sub-agents.

## Task 1: Admin campaign banner

Add a campaign-status banner to `apps/admin/src/app/dashboard/page.tsx`. It must
fit the application's installed dependencies and operational dashboard conventions.

## Task 2: Admin settings validation

Add validation feedback, an error summary, and form actions to
`apps/admin/src/app/settings/page.tsx`. Follow the APIs and layout conventions
applicable to that application.

## Task 3: Storefront merchandising message

Add a customer-facing promotional message to
`apps/storefront/src/app/promotions/page.tsx`. Follow the installed design-system
API and storefront voice.

## Task 4: Banner migration

Prepare a complete migration of one selected Banner consumer from design-system v2
usage to v3 composition. Identify all dependency and source changes required before
editing.

## Task 5: Banner internals

Add a new Banner variation in
`packages/design-system/src/components/banner.tsx`. Preserve package architecture
and identify testing, API-review, and release implications.
